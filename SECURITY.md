# Security

## Reporting a vulnerability

Email [notes@foodnotes.org](mailto:notes@foodnotes.org).

Please use email for security reports. A public GitHub issue is fine for a wrong FoodEx2 code.

This covers this repository (the encoder library and the local stdio server) and the hosted service at https://foodex2-encoder.foodnotes.org/.

Include the version or commit, what you did, and what someone could do with it — for example, reading another account, seeing food descriptions they did not send, or exposing an API key.

## What to expect

I will acknowledge the report within one business day. If it is a vulnerability, I will fix it before any public write-up. Please wait until that fix is published. If you have not heard back for 90 days, you may publish.

## Supported versions

Fixes go into the latest code on the default branch, and into the hosted service as it is deployed.
